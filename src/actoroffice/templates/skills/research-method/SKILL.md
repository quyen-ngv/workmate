# Research method

1. Restate the question and the decision it supports; list 3-6 sub-questions and the criteria for comparison.
2. Search broadly (several phrasings, English + Vietnamese when relevant), then read primary sources: official
   docs / pricing pages, standards, filings, papers. Use secondary sources only to find primary ones.
3. For each key claim keep: the claim, source URL, date published / accessed, and whether a second independent
   source confirms it. Prefer information from the last 12-24 months; flag anything older.
4. When sources conflict, show both and explain which you trust and why.
5. Confidence per finding: high (≥2 independent primary sources agree), medium (one primary source),
   low (secondary or inferred).
6. Write the `report` with the doc-standards report template; cite as [n] linked to the numbered sources list.
   Never present a guess as a fact.
